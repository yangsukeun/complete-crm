# 김정신 팀장 지정 직원 업무일지 조회 복구

2026-10-28. 운영 기준 7d2ce98에서 독립 분기. 문의 코드와 미배포 대표자료 제한 42263f1은 포함하지 않는다.

## 읽기 확인

김정신은 활성 TEAM_LEAD, 마케팅 부서이며 사용자 및 직급별 권한은 null이다. 운영 TEAM_LEAD 기본값에는 work_log_view_staff/admin_logs가 없어 메뉴와 API가 막힌다. 과거에 보였던 시점과 변경 원인 커밋은 이번 검증에서 확인하지 않았다. 미배포 42263f1이 현재 운영 차단 원인은 아니다.

실제 활성 계정으로 확인한 대상은 이하연, 박해린, 정세영, 최나영이다. 정확한 계정 ID는 work-log-review-scope.ts에 고정되어 있다. 조보미는 활성 마케팅 MD이지만 ‘봄MD’와 동일 인물이라는 별칭 근거는 없어 확인 전 제외한다. 실제 일지 본문은 조회하지 않았다.

## 최소 변경

- 김정신 ID + 활성 TEAM_LEAD + 마케팅 부서 조건에서만 지정 대상 조회 허용.
- 대상도 활성 USER + 마케팅 부서인지 매번 서버 검사. 대표/미지정/타부서/비활성은 직접 API에서도 차단.
- 페이지 목록 및 메뉴 진입에 동일 경계 적용. 다른 팀장·직원·이체담당자 권한은 확대하지 않음.
- 직원 일지 GET은 기존 기록만 읽고 없는 날에는 404. 본인 초안 생성 및 본인 수정 흐름은 유지.
- 날짜 검증 및 개인 응답 캐시 차단.
