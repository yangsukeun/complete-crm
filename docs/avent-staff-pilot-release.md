# 아벤트 지정 담당자 합성시험

기준 커밋: `2c63cfa8598a7e4ef4e294dc4ce2d416aeac9c1c`.
별도 브랜치: `avent-staff-pilot`. 운영 push 및 배포는 CRM 작업 간 순서 조율 후 진행한다.

## 대상과 범위

2026-11-05 기존 CRM DB에서 `name = 조보미`로 읽기 전용 조회한 결과는 1개였다.
ID `cmqu62595000d94im1hdpj79t`, 부서 마케팅, 역할 USER, accountDisabled false.
비밀번호·세션·토큰은 조회/생성/수정하지 않았다. 직원에게 연락하지 않았다.

대표 기존 ID와 위 직원 ID만 `/logistics/orders`, `/api/avent/pilot`을 이용한다.
서버는 현재 계정 존재·활성 상태와 ID 일치를 검사하며 계산 후 다시 확인한다.
역할 ADMIN/부서/이름 일치만으로 허용하지 않는다.

조보미 계정의 상단 3PL 메뉴와 `/logistics` 홈 진입만 추가한다.
현재 마케팅 소속에서는 아벤트 시험 카드 1개만 표시한다.
`workspaceAreas` 및 영업·정산·OCR·ERP 데이터 권한은 변경하지 않는다.

## 직원 사용 방법

1. 본인 기존 CRM 계정으로 로그인한다.
2. 상단 3PL → 아벤트 합성파일 시험, 또는 https://www.cpcrm.co.kr/logistics/orders 로 접속한다.
3. 합성자료 시험 시작 → 기대 결과 일치 확인 → 합성 결과 다운로드.
4. Excel 3행, 수량 4개, 금액 800원을 확인한다. 계산 중 중지 후 재실행할 수 있다.

이 경로는 배포 후 제공된다. 배포 전 운영 링크는 기존 대표 전용 화면이다.
실제 고객파일 업로드, 실제 발주, 재고/ERP 수정, 외부 전송은 지원하지 않는다.
고정 합성 XLS만 처리하고 서버에 결과/승인 기록을 저장하지 않는다.
128바이트 JSON `{action:"run"}`만 허용하며 Origin·파일 주입 차단은 유지한다.

## 검증과 한계

- 7개 테스트 파일 28개 검사 통과: 대상 직원/대표 허용, 다른 STAFF/ADMIN/비로그인 거부, 계정 비활성화/삭제/ID 불일치 거부, 계산 도중 비활성화 시 결과 차단.
- 실제 Node adapter와 합성 엔진으로 출력 Excel 3행·4개·800원 확인.
- Origin, JSON 추가 필드/파일 주입/초과 본문/multipart 거부.
- 서버 페이지와 홈 플래그 검사, 직원 홈 카드 1개·데이터 링크 없음, 다른 직원에게 시험 카드 숨김, 기존 3PL 업무 권한 유지.
- TypeScript 검사와 Next webpack 프로덕션 빌드(종료 코드 0) 통과. 추적된 worker 및 xlsx 26개 파일만으로 격리 패키지 합성 실행 통과.
- 지원 브라우저에서 변경된 UI 렌더·실행·기대 결과 일치, 중지·늦은 응답 폐기·재실행 성공 확인. 로컬 합성 harness는 실제 CRM 인증을 사용하지 않는다.
- 운영 링크는 기존 대표 세션으로 열기·합성 계산 일치를 확인했다. 변경된 직원 권한의 운영 검증은 아직 아니다.
- 첫 브라우저 다운로드 이벤트 확인 호출은 중단됐다. 그 호출의 파일 저장 결과는 불확실하며 새 다운로드 완료로 보고하지 않는다. 출력 Excel 내용은 엔진 검사에서 검증했다.
- 조보미 본인 로그인 검수, 고객 실파일, 실발주는 미실행.

## 통합 및 배포

부모 작업에서 이 브랜치의 커밋을 최신 main에 cherry-pick한다. 변경 파일 중 `app/workspaces/[area]/page.tsx`, `src/components/workspace-home.tsx`, `src/lib/workspace-page-access.ts`는 다른 CRM 작업과 겹칠 수 있어 충돌 시 해당 작업 내용을 보존한다.
통합 후 위 7개 테스트, `npx tsc --noEmit`, `npx next build --webpack`, `node tests/avent-pilot-trace-smoke.cjs`를 확인한다.
main push 전 최신 원격 커밋을 다시 확인하고 합의된 순서에 따라 1회 배포한다. 새 서비스/DB 마이그레이션/환경변수/비밀키/유료 리소스는 필요 없다.
배포 후 대표 세션 회귀와 비로그인 401, 조보미 본인 기존 로그인에서 3PL 카드→합성 실행→다운로드를 확인한다.
