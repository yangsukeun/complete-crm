## 채팅 인앱 알림

기존 Notification GET/Realtime 이벤트를 사용한다. 다른 방의 신규·갱신 미읽음 알림은 화면 팝업, 소리는 기본 off이며 사용자가 켜야 한다. 같은 방을 보는 탭/플로팅 창은 억제한다. Web Locks와 사용자별 이벤트 기록으로 다중 탭 중복 방지, 같은 방은 최신 팝업으로 합치며 최대 3개, 소리는 10초당 최대 1회. 닫기는 읽음 처리를 호출하지 않는다. 초기 로딩의 과거 알림은 팝업하지 않고 기존 배지를 유지한다. 비활성 탭은 폴링 중단, 활성 복귀 후 재조회. 설정 off는 팝업 제거; 브라우저 저장소와 Web Locks가 없으면 팝업 생략, 기존 배지·푸시 유지.

이 변경은 인앱 팝업/선택 소리다. 기존 OneSignal 구독·OS 권한·서비스워커·서버 푸시 정책은 변경하지 않는다. 따라서 기존 최근 3분 CRM 활동 시 푸시 생략/미읽음 병합 푸시 생략은 남는다. 브라우저를 닫은 상태의 실제 직원 기기 수신은 검증하지 않았다. 새 키/알림 허용 자동설정/실제 테스트 메시지 없음.
