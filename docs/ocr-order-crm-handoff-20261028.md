# CRM OCR·발주 AI 연결 준비 (2026-10-28)

운영 기준 ff2c260은 유지한다. 이번 작업은 로컬 코드와 합성 검증이며 운영 연결 완료가 아니다.

## 완료한 독립 코드
- `/logistics/ocr`: 기존 CRM 세션과 최신 DB 사용자 부서/활성 상태로 대표·물류만 진입. 브라우저 내 사진 미리보기와 제거, 연결 대기 안내. 업로드·OCR·승인·입고 버튼은 비활성.
- `/api/logistics-ocr`: 동일 서버 권한, no-store, 동일 출처 검사. ERP 어댑터 미등록 상태의 POST는 503이며 저장하지 않는다.
- 검수 재개 어댑터: 고객사/검수ID/최신 revision/권한/종료 여부 검사 후 HTTPS ERP resume 경로만 반환. 링크가 입고 승인이라는 뜻은 아니다.
- OCR 결과 수락 계획: 장치/회사/만료/취소/문서 revision 검사, 결과 해시와 중복 receipt 검증. 영속 트랜잭션과 정확한 worker 결과 스키마 검증을 주입해야 사용할 수 있는 순수 함수이며, 운영 큐 API가 아니다.
- `/logistics/orders`: 발주 검수 전용 진입과 실제 미연결 표시. 조회/다운로드 경계 함수는 최신 회사·사용자 권한, 타인 작업 차단, 다운로드 전 재검사를 수행한다. 주문 발송 인터페이스 없음.
- 이체 담당자 메뉴: 새 읽기 전용 `/api/finance/access`로 기존 활성 지정 여부를 확인. 계정별 캐시와 응답 사용자 일치 검사. `/finance/requests`에만 예외 적용하며 견적·인사·개인 대화·대표 영역 및 쓰기 권한은 확대하지 않는다.

## 다른 작업과 결합 지점
- OCR 계약: photo-inbound-v3 e980292, `/api/3pl/ocr-worker/claim`, `/jobs/:id/lease`, `/image`, `/result`. 서버 장치 등록 검증·원자적 배정·비공개 원본 읽기·결과 수락 저장을 붙여야 한다. 이 경로는 현재 CRM에서 활성화하지 않았다.
- ERP resume: `/inbound/photo/resume?review=…&company=…&revision=…`. 실제 ERP 호스트와 사용자/고객사 매핑은 미확정. localhost 3229를 직원 서비스로 사용하지 않는다.
- 아벤트: CRM-HANDOFF-1028.md의 bridge는 로컬 파일 저장소와 Node24 worker 실행을 전제한다. 현재 Vercel CRM에 이 로컬 경로를 연결하거나 loopback 토큰을 넘기지 않는다. 최신 회사 권한 조회기와 운영 작업 저장소/실행 서비스를 먼저 확정해야 한다.

## 추가 적용 범위 (이번에는 미실행)
1. OCR 장치 등록/허용 회사/만료·회수, 문서/비공개 원본 참조, 작업 lease, 결과 receipt·감사 이벤트의 영속 객체 및 인덱스. device+company, document+revision, job+lease+digest 고유성, row-lock 원자 처리 필요. 정확한 DDL은 기존 ERP DB 접근·모델 확인 후 결정한다.
2. 사진 전용 비공개 저장소와 세션/장치 범위 다운로드. 공개 URL이나 클라이언트 사진경로 허용 금지. 새 장치 인증 15분/등록 7일 제안은 아직 미승인.
3. 아벤트 지속 실행 위치, 회사/사용자 격리 저장, 중복 실행 잠금·보유기간·업로드 제한. 새 서비스/키/권한은 별도 확인.
4. ERP 입고는 기존 ERP 권한·최신 revision·명시 확인·원자적 입고 경로로만 연결. 실제 재고 기록 검수와 직원 E2E는 미실행.

기존 CRM 데이터·직원 부서·계정·비밀값·버킷 정책을 변경하지 않았다. 외부 OCR 전송, 실제 발주/재고 쓰기, 송금도 없다. 원복은 로컬 변경 커밋을 되돌리면 되며 DB 복구 작업은 없다.

## 이번 검증 결과
- 관련 합성 테스트 29건 통과(재무 메뉴/범위/팀장 19, OCR 경계·API·결과 수락 8, 발주 조회·다운로드 2).
- 전체 TypeScript와 Next production build 통과. 변경 파일 ESLint 통과. 기존 전체 린트 부채가 해결됐다는 뜻은 아니다.
- 로컬 Playwright의 `http://127.0.0.1:4318/verification-ocr` 이동은 `ERR_NETWORK_ACCESS_DENIED`로 차단되어 화면 클릭/모바일 검수 미완료. 우회·재시도하지 않았다.
- 실제 직원 로그인, 업로드/worker/ERP 입고, 발주 엔진·실물 XLS, 운영 배포는 이번 검증에 포함되지 않는다.
