# 전 직원 CS TEST 접근

사용자 요청에 따라 활성 직원 USER/TEAM_LEAD/CENTER_CHIEF/EXECUTIVE/ADMIN 계정에 CS TEST 페이지와 기존 격리 저장 API 접근을 허용한다. 부서 제한은 없다. 로그인 및 DB 계정 상태 검증, 비활성 계정 차단, 동일 출처 저장 검사, 버전 충돌 검사는 유지한다. 운영 연차·직원 관리·DB 구조·계정 역할은 변경하지 않는다.

CS 하위 메뉴의 TEST 링크는 일반 직원에게도 표시한다. 직접 주소는 /cs-tools/test이며 기존 CRM 계정으로 로그인해야 한다. 공유 TEST 사본의 신청·승인 시험과 저장 결과는 다른 허용 직원에게도 보인다. 실자료 이전은 0건이며 현재 사본은 합성 시험 자료다. 추후 실제 직원 자료를 반입할 때는 전 직원 공개 범위를 별도로 재검토해야 한다.

검증: API를 모의 저장소에 연결해 일반 직원 목록/저장/재조회, 익명·비활성·누락 계정 및 외부 출처 저장 차단을 확인했다. 관련 28개 합성 테스트 통과. 기존 격리 PostgreSQL 시험의 역할 기대값도 갱신했지만 이번에는 실제 DB 시험을 재실행하지 않았다. 실제 직원 세션 UI 검수는 브라우저 안전 중단으로 미실시다.
