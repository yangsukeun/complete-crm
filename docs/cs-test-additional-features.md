## 추가 기능

- 보고서 검산: 정규화한 JSON의 일별 채널 합계, 고객사별 월 합계, 합계행 제외, 원본 위치 중복 제외, 값 충돌 격리, 미래 빈 날짜와 0 구분, 원본 합계 불일치 보존. 직접 시트 자동 연결이나 전체 220탭 동일 구현은 아니다.
- 기본 통신사 응대율: 총 응대/총 수신. 콜백 보정 산식은 원본 미확인이므로 구현하지 않았다. 보고서 입력은 페이지 메모리이며 휴가 서버 저장 대상에 포함하지 않는다.
- 새로운 합성 검사 5개 + 기존 17개 = 22개 통과. TypeScript와 변경 파일 ESLint 통과. 격리 PostgreSQL/HTTP 저장 검증 1개 시나리오는 별도 통과했다.
