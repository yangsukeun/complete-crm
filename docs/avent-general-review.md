## 변환과 판단 경계

- 모든 비어 있지 않은 원본 행의 값·순서·중복 횟수와 Excel 행 번호를 보존한다. 완전한 빈 행만 결과 표에서 생략한다. 키를 숫자로 변환하지 않으며 이미 숫자로 저장된 키는 확인 대상으로 표시한다.
- 쇼핑몰 주문/부주문/사방넷 주문/쇼핑몰/상품/AVK 코드는 분리된 값이다. 부주문·옵션 공란을 일괄 오류로 처리하지 않는다. 복수 AVK 행과 같은 7열 결과도 삭제하거나 세트로 재증식하지 않는다.
- 매핑 누락, 정수가 아닌 양수 수량, 수량 차이, 불명확한 상태·키, 동일 행 반복, 같은 키의 내용 차이는 보류 검토 항목이다. 자동 보정/승인/삭제는 없다. 현재 `신규주문` 이외 상태는 검토 대상으로 남기며 운송장 공란으로 상태를 추정하지 않는다.
- 합계는 **원본 행 주문수량 합 / 원본 행 출고수량 합**이다. 실제 판매주문 수량 또는 출고 확정 총계로 해석할 수 없다.
- 비교본은 복합키와 반복 횟수의 다중집합으로 같은 배치인지 대조한다. 같은 배치라도 내용이 다르면 표시한다. 비교본이 없으면 과거 처리/배치 일치를 확인하지 않는다.
- 상품 마스터/승인된 최신 매핑 버전이 없으므로 업무상 매핑 정답을 판정하지 않는다. 별도 상태 선택/매핑 버전 선택/검토 승인 저장 기능도 없다. 원본 또는 비교본 변경·중지·초기화·이동은 기존 결과를 무효화한다.
- A1로 잘못 선언된 XLSX dimension은 실제 셀 범위로 읽는다. ZIP의 로컬 크기 0은 검증한 중앙 디렉터리 크기를 메모리 사본에만 반영한다. 원본 바이트와 SHA-256은 유지한다.

## 결과와 개인정보

브라우저 Worker에서만 파싱·검수·XLSX 생성을 한다. 새 서버 업로드 API, 파일 저장, AI/API 발주 연결은 없다. 기존 `/api/avent/pilot` GET은 실행 전과 다운로드 직전 현재 계정 접근권한만 확인하며 파일 데이터/이름을 보내지 않는다.

검수용 Excel의 첫 시트는 업로드 금지 안내다. 나머지는 채널 대조, 7열 매핑 검토, 원본 30열+행 추적, 예외 코드다. **수령자를 포함한 원본 고객정보는 이 로컬 Excel 안에 남는다.** 비식별 파일로 공유하면 안 된다. JSON 보고서에는 고객 셀 값·주문키·파일명·실제 채널명을 넣지 않고 행 수·검토 코드·채널 별칭·수량 합·날짜 범위·원본 해시만 넣는다.

원시 파싱 오류는 Worker 안에서 고정 오류로 바꾸며 Worker console 및 전역 오류 전파를 막는다. UI 오류도 고정 문구이고 고객값을 DOM에 표시하지 않는다. Sentry 전역 설정은 변경하지 않았다. 정상/오류/재처리 Worker에서 합성 식별 문자열이 보고서·console·네트워크 호출로 나가지 않는 검사를 포함한다. **실제 production Sentry를 켠 전체 네트워크 검수는 아직 미실행**이다.

Worker 종료·10초 처리 제한·파일/행/셀 길이 제한·ZIP 엔트리/압축해제 용량 제한을 둔다. XLSX는 실제 스트림 압축해제 크기도 검증한다. 수식·셀 오류·하이퍼링크·매크로·명명 범위·외부 연결·암호화 ZIP·여러 시트는 미지원이다. 브라우저 힙의 강제 상한을 보장하지 않으며 기존 SheetJS 0.18.5 의존성을 교체하지 않았다. 구형 브라우저가 필요한 압축해제 API를 제공하지 않으면 안전한 오류로 종료한다.

## 화면·권한·검증

배포 시 경로: `3PL 홈 → 일반몰 파일 검수 · 업로드 불가`, `/logistics/orders/general`.
기존 대표 및 조보미의 명시적 허용 ID와 최신 비활성 검사만 재사용한다. 계정/역할/부서/DB/기존 실물류 권한 변경은 없다. 다른 직원·관리자·비로그인·비활성은 기존 경계대로 차단한다.

사용 순서: ① 30열 원본과 필요시 같은 배치 비교본 선택 ② 파일 검사 후 행별 보류와 합계 차이 확인 ③ 검수용 Excel/보고서를 내려받아 담당자가 규칙을 확인한다. 다운로드는 발주 승인/완료가 아니다.

최종 관련 회귀 7개 파일 / 41개 테스트 통과. 메뉴 문구 변경 후 홈 2개 테스트도 재통과. 합성 검사: XLS/XLSX, 26자리 문자열 키, 빈 옵션/부주문, 분리된 세트와 중복 보존, 다른 배치/반복 횟수, 미매핑/수량/상태, A1 dimension, ZIP 크기 0 및 거짓 크기, 수식/외부 연결/오류 파일, Worker 개인정보 경계, 기존 페이지·상위 접근권한 회귀. 로컬 브라우저에서는 합성 정상 완료, 중지 후 늦은 결과 폐기, 초기화/재선택/재실행, JSON 다운로드와 고객 식별문자열 제외, 오류 파일 재선택에 따른 이전 결과 폐기와 고정 오류 문구 및 console 무출력을 확인했다. 빌드와 TypeScript도 통과했다.

브라우저 harness는 테스트 전용 가짜 권한 GET이며 production에 배포하지 않는다. 조보미 본인 로그인, 실제 고객파일 처리, 운영 Sentry 전체 검수, 실제 업로드/발주 검수는 미실행이다. 운영 반영 전 최신 main 통합 검사를 다시 해야 한다. 실업로드를 열려면 확인된 이지어드민 양식과 최신 매핑 근거가 별도로 필요하다.
