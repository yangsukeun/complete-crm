## 데이터 권한과 미확정 범위
- CS 홈은 기존 로그인 사용자에게 도구 링크와 본인 근태를 표시. 라운지·생일·조직·담당거래처·직원 근태·연차는 기존 각 권한 유지. 일반 경영지원에 직원 개인자료를 새로 공개하지 않음.
