# 대표 전용 고정 합성파일 파일럿

이 문서는 최초 대표 전용 배포 기록이다. 2026-11-05 지정 담당자 합성시험 변경 및 현재 검증 범위는 [avent-staff-pilot-release.md](avent-staff-pilot-release.md)를 참조한다.

운영 기준 faeb55a를 보존하는 별도 작업본. 승인 범위는 대표 기존 계정만, 고정 합성파일만이며 고객파일/직원 권한/실제 발주를 개방하지 않는다.

- URL: /logistics/orders, API: /api/avent/pilot.
- 기존 getAppSession → WORKSPACE_OWNER 일치 → 최신 User.accountDisabled 검사. 계산 뒤 동일 검사를 반복한다. ADMIN 역할만으로 허용하지 않는다.
- API는 `{action:"run"}`만 받는다. 파일/회사/양식/추가 필드를 거절한다. 원본과 기대 XLS는 서버의 고정 합성 상수에서 만든다.
- 3행, 주문2개, 수량4개. 300원 반복 결제행1개만0으로, 합계800원. 실제 고객자료 없음.
- 서버 무저장, 요청128바이트/읽기1초, 계산2초, 응답256KiB. 파싱 스레드1건/프로세스, 종료·취소 처리. 거래처/ERP/메일 연결 없음.
- 화면에 파일 입력 없음. 중지는 요청 취소 및 결과 폐기이며 원격 주문 취소가 아니다. 늦은 응답은 generation 검사로 폐기한다.
- 같은 대표 계정의 기존 3PL 화면에 파일럿 링크만 추가. CS/OCR/진행보드 내용과 권한을 바꾸지 않았다.
- 알려진 PPTX 브라우저 빌드 오류 수정은 별도 커밋이며 기존 검증된 최소 수정이다. Prisma schema/환경변수/자격증명/DB 정책 변경 없음.

로컬 검증: 권한/입력 제한4개 테스트, 실제 Node adapter→제한 엔진 합성 실행, 브라우저 시작·다운로드·중지·재시작(3행/4개/800원), TypeScript 및 대상 ESLint. 실제 운영 배포와 온라인 검수 결과는 최종 보고에서 커밋/배포 상태와 함께 구분한다.

실행 패키지는 Next outputFileTracingIncludes로 engine CJS 및 xlsx를 포함한다. `node tests/avent-pilot-trace-smoke.cjs`로 해당 추적 파일만 별도 디렉터리에서 합성 실행 검증한다. 새 서비스/키/저장소는 필요하지 않다.

이 파일럿은 실제 고객사 검수 권한을 만들지 않는다. 고객파일 업로드나 직원 사용을 열려면 별도 승인과 고객사 매핑이 필요하다.
