# 업무영역·3PL 운영 화면 적용 범위

- 기존 getAppSession과 DB 최신 department를 사용한다. 물류/물류팀/물류창고/3pl은 logistics, 마케팅/마케팅팀은 marketing, CS/CS팀/CS센터는 cs, 경영지원/경영지원팀은 management. 미등록값은 추정하지 않는다.
- 대표 정확 ID만 네 영역 전체, 일반 ADMIN/다른 부서는 3PL 경로 접근을 추가 허용하지 않는다. 기존 org-access의 물류 로그인 기본홈 /logistics를 유지한다.
- /workspaces, /workspaces/[area], /logistics에서 부문 홈 제공. 기존 업무영역 메뉴 추가. 기존 채팅/재무/업무 기능 자체는 변경하지 않는다.
- 새 문의·계약·월 청구·인력·급여 저장은 준비 중 안내만. 합성 계정, SQLite, local-review, 개인 rua 메뉴, 새 DB 모델, OCR 코드, 외부 AI/은행 연결은 이 커밋에 없음.
- 급여/계좌 데이터 조회 없음. 대표에게만 미연결 급여 카드 표시. 기존 링크는 해당 기능의 정상 권한 검사를 그대로 거친다.
- 롤백은 직전 앱 커밋으로 복구. 이 화면 배포는 DB/권한/기존 데이터 변경이 없어 역마이그레이션 불필요.
- 실제 브라우저 로그인 검증은 URL 식별 정책 차단 때문에 미실행. 서버 접근 분기와 합성 테스트, 타입·lint·빌드 및 배포 후 비로그인 리다이렉트로 확인 범위를 구분한다.
